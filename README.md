# SQL Practice Workbook for Beginners: sample database

This repository has the database script used in the book
"SQL Practice Workbook for Beginners: 100 Hands-On Exercises with Tested Answers" by Hamza Khan.

## How to use it
1. Create a new, empty SQLite database.
2. Open `database_script.sql`, copy everything, paste it into your SQL tool, and run it once.
3. Check that it worked: `SELECT COUNT(*) FROM customers;` should return 60.

All data is fictional.
